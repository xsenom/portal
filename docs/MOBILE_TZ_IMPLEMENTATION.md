# Реализация мобильного приложения VolgaShield

## Авторизация

Сейчас используется собственный API `/auth/login`.

Интеграция с Bitrix24 должна подключаться как отдельный провайдер авторизации. Экран приложения менять для этого не требуется.

## Главный экран

- статус смены;
- начало смены с геолокацией и устройством;
- пауза с причиной;
- возобновление;
- завершение с серверной проверкой активных заявок;
- пять последних активных заявок;
- переходы в список, архив и профиль.

## Список заявок

- поиск;
- фильтр по статусу;
- фильтр по периоду;
- фильтр по объекту;
- сортировка;
- pull-to-refresh;
- SLA;
- метки брака и повтора;
- прогресс выполнения.

## Карточка заявки

Для активной заявки используется существующий экран:

- объект;
- договор;
- контакты;
- история;
- исполнители;
- чек-лист;
- комментарии;
- вложения;
- штрих-код;
- действия по статусам.

## Архив

Архив доступен только в рамках серверных прав текущего техника. Архивная карточка открывается в отдельном режиме только для чтения.

## Профиль

- фото;
- ФИО и должность;
- мои закрытые заявки;
- статистика;
- личные данные;
- переход в админку для администратора.
